# Generative AI Fundamentals

## What Are Large Language Models (LLMs)?

Large Language Models (LLMs) are machine learning models trained on large amounts of text to understand and generate human-like language. They learn statistical patterns in language and use those patterns to predict tokens and generate responses.

LLMs can perform tasks such as answering questions, summarizing documents, translating text, generating code, and following instructions. Their outputs can still contain incorrect or fabricated information, so important answers should be checked against reliable sources.

## What Is Transformer Architecture?

The Transformer is a neural network architecture widely used in modern language models. Its key innovation is the attention mechanism, which allows the model to determine how different tokens in a sequence relate to one another.

Transformers commonly use token embeddings and positional information to represent input text. Self-attention combines information from relevant tokens, while feed-forward layers further process the resulting representations. Stacking these components allows the model to learn complex relationships in language.

## What Is Self-Attention?

Self-attention calculates how much importance each token should give to other tokens when building its representation. This helps a model use context from different parts of a sequence when processing language.

## Common Applications of Generative AI

Generative AI can produce text, code, images, summaries, and other content. Applications include chatbots, coding assistants, document analysis, content generation, and question-answering systems.
