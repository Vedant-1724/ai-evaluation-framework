# Machine Learning Fundamentals

## What is Supervised Machine Learning?

Supervised machine learning is a type of machine learning in which a model learns patterns from labelled training data. Each training example contains input features and a known target or correct answer. During training, the model adjusts its parameters to make predictions that match the known targets. After training, it can use learned patterns to predict outcomes for new, unseen inputs.

## What Is the Difference Between Regression and Classification?

Regression and classification are two main types of supervised learning.

**Regression** predicts a continuous numerical value. Examples include predicting house prices, delivery times, or temperature.

**Classification** predicts a discrete class or category. Examples include classifying an email as spam or not spam, identifying an image as a cat or dog, or predicting whether a transaction is fraudulent.

The key difference is the type of output: regression predicts a number, while classification predicts a category.

## Common Applications

Supervised learning is used for price prediction, demand forecasting, image recognition, spam detection, fraud detection, and customer churn prediction.
